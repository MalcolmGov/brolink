# Brolink — AI & Automation Opportunity Assessment

Built by MTN Group Fintech — AI & Automation Team for Brolink (brolink.co.za).

## Contents

- **`index.html`** — Interactive demo prototype for Brolink executives
  - Claims AI: click-to-process document extraction demo
  - Broker AI Assistant: conversational chatbot with SA insurance domain knowledge
  - Compliance Dashboard: live health monitoring across POPI, TCF, FSCA
  - Opportunity Cards: top 3 scored interventions
  - ROI Calculator: adjustable deployment scope with real-time savings estimates
  
- **`Brolink-Opportunity-Assessment.pdf`** — Full 8-page report including:
  - Executive summary & company profile
  - 12 scored AI opportunities across the value chain
  - Recommended 90-day sprint plan
  - Commercial model options
  - Competitive context & next steps

## Quick Start

```bash
# Clone
git clone https://github.com/MalcolmGov/brolink.git
cd brolink

# Open the prototype
open index.html
```

No dependencies, no server needed — the prototype is a single self-contained HTML file.

## Deploy to GitHub Pages

Enable GitHub Pages in repo Settings → Pages → Source: main branch → `/ (root)`.  
The prototype will be live at `https://malcolmgov.github.io/brolink/`
