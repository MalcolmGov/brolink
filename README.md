# Brolink — From Admin to Advantage

Interactive working-session demo for Brolink executives. Built around the 2030 Strategy: *insurance administration done right — through people, technology, and partnerships.*

Live: https://malcolmgov.github.io/brolink/

This is a **layer alongside Websure**, not a replacement. It does not settle claims and it does not replace underwriting judgement.

## What the room walks through

1. **Email desk** — status and cover auto-send; vehicle / address / specified item / debit-date endorsements confirm-before-write; unpaid debit notifies the broker (re-present stays financial); commission escalate; cross-book refuse. Agent trace shows intent, book, and isolation.
2. **Phone wrap** — 41-second DID call with Nadia becomes a young-driver endorsement draft. Under-25 is underwriting judgement, not auto-bind. Files onto the same Broker Desk.
3. **Broker morning** — Nadia Petersen on WhatsApp: claim status, specified-item confirm-before-write, multi-quote as advice support.
4. **Claims cell** — FNOL pack is read (photo, licence, quote), reconciled to the Santam binder, expired licence chased. Settlement stays with the assessor. Agent trace is visible.
5. **Binder supervision** — per-insurer bordereaux, TCF, DSARs, collections exceptions.
6. **Isolation** — Hollard workspace searching a Santam claim is refused with an audit line.
7. **Connect** — mailbox → classified actions → Websure / Astute. Read, write, financial.
8. **Working session pack** — 90-minute agenda, talk track, who must be in the room, discovery questions.
